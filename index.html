Pemeriksaan & Penskoran Esai Manual

Panduan Pengoperasian Offline

1. Pelaksanaan Ujian Tanpa Internet:

Buka file index.html pada browser HP siswa (Chrome/Safari). Tidak memerlukan jaringan atau kuota internet.

2. Pengumpulan Hasil:

Siswa mengunduh file .json setelah selesai, lalu menyerahkan file tersebut via Bluetooth/WhatsApp/OTG ke Guru.

3. Pengolahan Nilai oleh Guru:

Buka Panel Guru -> Tab "Rekap & Impor Hasil" -> Pilih semua file .json -> Klik "Proses Impor". Lakukan koreksi esai lalu ekspor rekap ke CSV.
